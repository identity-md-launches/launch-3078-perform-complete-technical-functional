## Remaining operational and verification limits

The static export is a functioning device timer/profile plus real read-only chain view. **Shared accounts, multi-user rooms, shared expeditions and a shared league require operating the existing Python backend on the frontend's origin.** No public service URL was supplied or invented. They were verified against an actual local server and disposable SQLite database, not a browser-only simulation. Device mode explains this requirement instead of imitating shared state.

Focus records measure elapsed timer duration, not proof of human attention. Device storage is editable and not shared evidence. Clearing it removes personal records. No automatic migration/uploads of personal records to server accounts are implemented. Server mode is the existing small single-process SQLite architecture; rate limiting, TLS, durable backups, abuse moderation, password recovery, monitoring and multi-instance scaling need operator work or future scoped development. Default local HTTP remains convenient; the documented HTTPS operator command enables Secure cookies.

No WebKit/Safari, real iOS/Android, manual screen-reader, browser-native 200% zoom, translated-content, sustained-load, penetration or public backend-deployment test was completed. No claim of independent certification or production availability is made.
